## 3. Краткое математическое описание модели

### 3.1. Сетевая структура и переменные
* **Вершины предложения (источники):** $B = \{B_1, \dots, B_6\}$ — 6 специализированных ремонтных бригад; $b_i = +1$.
* **Вершины спроса (стоки):** $O = \{O_1, \dots, O_6\}$ — 6 технологических объектов энергокомплекса; $d_j = +1$.
* **Переменные решения:** $x_{ij} \in [0, 1]$ — непрерывная переменная потока (доля назначения бригады $i$ на объект $j$).
* **Параметры:** $c_{ij} > 0$ — время выполнения работ на объекте $j$ силами бригады $i$ (часы); $u_{ij} = 1.0$ — пропускная способность дуги.

### 3.2. Линейная оптимизационная модель
$$\min Z = \sum_{i=1}^6 \sum_{j=1}^6 c_{ij} x_{ij} \quad \text{(часы)}$$
при ограничениях:
1. **Баланс предложения в узлах бригад:**
   $$\sum_{j=1}^6 x_{ij} = 1, \quad \forall i \in \{1, \dots, 6\}$$
2. **Баланс спроса в узлах объектов:**
   $$\sum_{i=1}^6 x_{ij} = 1, \quad \forall j \in \{1, \dots, 6\}$$
3. **Границы переменных (пропускные способности дуг):**
   $$0 \le x_{ij} \le 1, \quad \forall i, j$$

### 3.3. Свойство полной унимодулярности (ТУМ)
Матрица инцидентности узлы-дуги двудольного графа $A_{\text{eq}}$ является вполне унимодулярной (Total Unimodularity, TUM), а вектор правых частей $b_{\text{eq}} = \mathbf{1}$ целочисленный. В силу теоремы Биркгофа–фон Неймана и свойств ТУМ все крайние точки допустимого политопа $\{x : A_{\text{eq}} x = \mathbf{1}, x \ge 0\}$ являются строго целочисленными: $x_{ij}^* \in \{0, 1\}$.  
Поэтому непрерывное ЛП-решение HiGHS гарантированно дает точное целочисленное назначение без использования ветвления и границ.
